Making a video

  • Start from a preset. Lesson, YouTube explainer, Short, course intro or quiz — each with sample scenes in your language.
  • One scene = one idea. Put the on-screen text in “Text” and what you say in “Narration”. Scene length follows the narration.
  • Pick the screen size for where it will play: 16:9 for YouTube, 9:16 for Shorts, TikTok and Reels, 1:1 or 4:5 for Instagram, 4:3 for classrooms.
  • Add your own images or video as a scene background (PNG, JPG, WEBP, MP4, MOV, WEBM). Uploads are kept for 24 hours.
  • Draft first. Tick “Draft quality” to check timing quickly, then render the final video.

Tips for better results

  • Punctuation sets the rhythm. Commas and full stops create natural pauses; use «،» and «.» in Arabic.
  • Arabic diacritics (تشكيل) help with ambiguous words, e.g. names and rare vocabulary.
  • Numbers and dates are read in the selected language; write them out if you need a specific reading.
  • Speed and pitch change delivery. Try −10% speed for clearer teaching.

FAQ

Is it free?

Yes. There is no charge to preview or export. Please be fair with long jobs.

Can I use the audio and videos commercially?

Voices come from Microsoft's neural text-to-speech service. Check Microsoft's terms, and make sure you own the rights to any images or clips you upload.

Is my content stored?

Text is sent to the speech service to generate audio. Rendered videos and uploaded backgrounds are deleted automatically after 24 hours.

How long can a video be?

Up to 40 scenes and about 15 minutes. Longer lessons are best split into parts.

Which scripts can appear on slides?

Arabic, Latin, Cyrillic and Greek always work. Other scripts (Chinese, Japanese, Korean, Hindi, Thai…) need the matching system fonts on the server; the narration works for every language either way.

About the module

One small module for voice and video.

VoiceForge is a Python package with two parts: tts_module.py (text to MP3 with Microsoft's neural voices via the open-source edge-tts) and video.py (scenes to MP4: slides drawn with Pillow, narration, burned-in captions, ffmpeg). The same code runs as a library, a command-line tool and a web API.

Use it from code

# Python — voice
from tts_module import export_mp3, voice_for
export_mp3("مرحبا بكم", voice_for("ar-SA", "male"), "hello.mp3")

# Python — video
import video
project = video.validate_project({"size": "youtube-1080", "theme": "academy",
    "voice": {"lang": "ar-SA", "gender": "female"},
    "scenes": [{"layout": "title", "title": "درس جديد", "narration": "أهلاً بكم في هذا الدرس."}]})
video.render_project(project, "lesson.mp4", assets=None)

# HTTP API
curl -X POST /api/export -H "Content-Type: application/json" \
  -d '{"text":"مرحبا","lang":"ar-SA","gender":"female"}' -o speech.mp3
